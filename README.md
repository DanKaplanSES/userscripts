# userscripts

Userscripts for [Tampermonkey](https://www.tampermonkey.net/) and other
userscript managers. Each script lives in its own folder, with a README that
explains what it does and how to use it.

These scripts have only been tested with Tampermonkey on Firefox. Other
browsers and userscript managers may work, but haven't been tried.

## Scripts

None published yet.

## Installing

Install a userscript manager such as Tampermonkey in your browser first. Then
install a script from its Greasy Fork page, so your userscript manager picks up
new versions automatically.
